# Histoire
Permet à A.V.A.T.A.R. de raconter des histoires directement à la voix.

- This plugin is an add-on for the [A.V.A.T.A.R](https://avatar-home-automation.github.io/docs) framework. 

 ## 🎯 Usage
Commandes :
- donne moi/raconte/joue , l'histoire du loup, ou met l'histoire de la belle et la bête
- crapichouille, madame midas, dromadaire, arnaud, petit chaperon rouge, petit poucet, la belle et la bête, cendrillon, loup, berger.
- 
## Multi-room

The Histoire plugin is fully multi-room.

## Multi-language

The Histoire plugin relies solely on the system's available languages.
